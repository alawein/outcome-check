# Brand

Siftgrain State helps agent evaluators inspect whether supplied state supports a
requested outcome. Its primary user owns a harness, collector, or CI workflow and
needs an explicit, reviewable result rather than another model judgment.
Integration points are the Python API, CLI, converters, GitHub Action, stdio MCP,
and single-file viewer.

Voice: **Show the change. Keep the evidence.** Short, specific, candid about
missing observations. Confirmed means the declared check passed, never that the
world is true or that an agent caused it.

The family is Siftgrain; the descriptor is State. Siftgrain Cite and Siftgrain
Audit are sibling products. [Name checks](docs/name-checks.json) record exact
GitHub, npm, PyPI, and Hugging Face searches plus a trademark-style web search
on October 13, 2026.
The search found no obvious competing software brand among returned Siftgrain
results. This limited search is not legal clearance. Spanward was rejected after
software collisions. Existing distribution identities remain compatible.

Original SVG geometry uses three stepped receipt/observation stations. It is
constructed from paths and rectangles, with no downloaded logo template or copied
personal artwork. [Logo](brand/logo.svg) and [wordmark](brand/wordmark.svg) remain
editable SVG. The palette comes from the shared unpublished suite token package,
with dark night-market violet, warm paper, amber accents, mint confirmations,
and pink contradictions. Light appearance has tested text/control contrast.

Use system sans-serif for long copy, Georgia for display, system monospace for
values. There are no downloaded fonts or CDN requests. Pixel changes corners and
stepped easing; Cartoon adds sticker shadows, uneven corners, transform squash/stretch and spring
easing; Calm adds guarded gentle pointer parallax and slower state settling; Lab tightens density. Nonessential motion stops under reduced motion,
pause, and hidden-page handling. A finite GPU sweep reveals the existing evidence
field and never changes a verdict. Color always accompanies a text state.

`design-tokens/` is an identical vendored copy of the family owner in Siftgrain Cite,
version 1.0.0, private and unpublished. `_tokens.py` embeds the exact CSS for
installed-wheel single-file reports; `scripts/check_perf.py` enforces equality.
No separate published runtime package is created.
